# Prepare translation with the service

1. In Community, open **Plan a service** and save the service.
2. Open **Translation settings**. The shared console selects that service automatically. From SyncShow, open **Live translation** and choose it under **Prepared service**.
3. Choose the speaker's language, Quality or Economy, translated speech, and any optional sermon notes. Select **Save for this service**.
4. On service day, select the service and review the saved choices. Connect the mixer on the computer receiving the church audio, then start translation.

Saving settings does not open a microphone, run a model, or publish the notes. Text translation continues with generated speech off. A service can use translation without slides; SyncShow's output screen controls remain separate from starting the shared session.

For Economy with sermon notes, the operator chooses whether to share the selected notes for that session. Saving remembers the note selection but does not remember that sharing choice. Relevant excerpts can help with names, Scripture wording and terminology; the translation still follows the spoken words. Notes can be disabled, or Quality selected instead.

If someone edits the service or its translation settings, reload and review before starting. Unsaved changes must be saved for the selected service. Archived or cancelled services are unavailable for preparation. **Unplanned service** remains available for translation without a prepared service.

This workflow requires the matching Community/Multilinguum component set and SyncShow Preview 27 or later for desktop access. The private plan does not change canonical slides, Ready status, or offline ShowPackages. Its selected service reference is retained privately with the translation session.
