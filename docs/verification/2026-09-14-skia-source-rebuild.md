# Mac Skia and Canvas source rebuild

Both Skia and the Canvas Rust/C++ wrapper now build from the retained source inputs on Apple Silicon. A separately re-signed Preview 28 copy loads the resulting addon and preserves the original preview’s tested English/Russian text, image and PDF output. This closes the earlier Mac dependence on upstream prebuilt Skia archives. Other targets and the complete desktop release remain unfinished.

The [exact input and result record](2026-09-14-skia-source-rebuild.json) contains dependency URLs/hashes, GN configuration, source correspondence, compiler versions, rebuilt libraries and rendering results. The preceding [Canvas wrapper record](2026-09-14-canvas-wrapper-rebuild.md) supplies the retained Rust lockfile, vendor inputs and the image-class regression that required pinning the N-API dependencies.

## Reproduce the build

Start with the isolated root described in the [Canvas wrapper recipe](2026-09-14-canvas-wrapper-rebuild.md), including its exact Canvas/Skia source archives, reviewed Cargo lockfile, `vendor-reviewed`, isolated Rust toolchain and CMake/Ninja environment. The previous upstream `skia-libs` directory may remain for comparison; the full rebuild does not link it.

Copy these three helpers into that build root:

- [collect-skia-deps.py](tools/skia-rebuild/collect-skia-deps.py)
- [build-skia-owned.py](tools/skia-rebuild/build-skia-owned.py)
- [build-full-canvas.py](tools/skia-rebuild/build-full-canvas.py)

Set `CANVAS_REBUILD_ROOT` to its absolute path and run:

```sh
python3 "$CANVAS_REBUILD_ROOT/collect-skia-deps.py"
python3 "$CANVAS_REBUILD_ROOT/build-skia-owned.py"
python3 "$CANVAS_REBUILD_ROOT/build-full-canvas.py" "$CANVAS_REBUILD_ROOT"
```

The collector retains each archive and receipt, safely extracts new trees, and verifies existing regular files against the archive rather than accepting a directory’s presence as proof of a completed extraction. It also downloads the pinned GN executable. Compare the collected hashes with the exact record before building. No upstream release-upload script is run.

The Skia helper runs the reviewed upstream script with six compiler jobs and requires at least 4 GiB free before starting. The full Canvas helper uses `--locked --offline`, a separate Cargo home, `vendor-reviewed` and Skia’s actual `out/Static` directory. Its result is:

```text
source-skia-target/aarch64-apple-darwin/release/libcanvas.dylib
```

Use the earlier [owner-copy replacement and probe procedure](2026-09-14-canvas-wrapper-rebuild.md) with this file. Preserve the copied bundle’s name `SyncShow.app` inside a separate parent folder. This procedure applies to the trusted ad-hoc preview; it does not modify an installed app or change any signing/security policy.
